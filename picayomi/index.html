1. 一段闲话

多年没有更新网站, 这个高中竞赛期间忙里偷闲搭建的网站, 也是被遗忘吃灰了. (所幸当年偷懒用 GitHub Pages 建的网站, 还能保证至少可以访问)

时代发展真快, 之前靠 Ctrl+C, Ctrl+V, 到处串门偷抄别人网站, 东拼西凑数周才逐渐搭好的博客, 如今 AI 大人一下午就能修缮如新, 甚至优化一番.

以前感觉日子快, 其实一点不快. 一杯茶, 一抖腿, 一段代码就是敲半天. 现在哪还打代码, 连看都不看了, C++ 更是一两年没碰过, 老本都忘了. 代码能力已经退化成"离开 AI 大人就是天才程序员的陨落", 如今那是连个平衡树都写不来了(

工作已有一年, 在成都过得还算自在, 一个人平日就是周末拍拍照(尼康佬), 打打游戏, 偶尔去天府红看看美女, 采购点动漫周边. 闲来无事, 还是要做点项目, 维护下博客, 无论是信息发布, 生活分享, 还是知识记录, 都发一点, 算是充实下生活.

闲话到此.

2. 前言

几年前买了个 Kpw6, 本来是想看看书啥的, 不过天性浮躁, 偶能遇到一本对胃口的书还可以静下来看看, 看完后就是长久的吃灰. (本INFJ安利下赫尔曼黑塞的书)

但是只有正经事用 Kindle, 应用范围还是太小了. 平日专门用 ipad mini5 看哔咔漫画, 这电子书, 不更是天生的漫画圣体吗?

一年前, 其实已经想到过用 AI 做这样一个项目, 移植 PicaComic 到 Kindle 上. 但是当时 agent 还不够成熟, 调试繁琐, 页面绘制也总遇卡点, 仅仅开了个头, 最终暂时搁置.

如今不到一周, 用 deepseek-v4.1-flash + gpt6.1-sol 配合, 也是顺利开发完成, 有了第一个正式版发布, 能力基本完善, 页面简洁美观, 性能也有优化, 使用体验上尽量对齐手机应用体验.

为了兼顾普通漫画的阅读, 也顺带搞了拷贝漫画的支持, 并且设计为漫画源形式, 便于后续增加新的漫画平台, 或是维护已有源的接口.

以下是项目展示.

3. 主页

主页是一排菜单. 顶上显示当前漫画源, 点一下就能换; 下面依次是最新, 分类, 排行, 收藏, 历史, 已下载, 搜索, 账号和设置. 漫画源支持的能力就会显示, 否则自动隐藏. 目前还比较简陋, 后续可能优化下主页样式, 感觉加点历史或者收藏的预览出来比较好.

目前支持哔咔, 绅士, 禁漫, 拷贝共 4 个源.

4. 浏览与列表

列表一行一本, 带有封面预览, 有些源的接口有作者, 话数, 页数之类的回参, 就也会显示出来. 底部一排是上页, 下页, 跳页, 排序, 也支持滑动的手势交互, 这样单手也能翻(

分类页是标签直接铺开, 点进去就是这个分类的列表.

5. 详情与阅读

漫画详情页顶部是封面和标题, 都可以点击, 封面可以放大显示, 标题可以复制, 包括描述部分也是可以点击展开看完整内容的.

标签和作者可点击, 用于关键词搜索.

阅读页基于 KOReader, 增加了边缘滑动退出的能力, 对齐手机体验. 以及性能上, AI 大人搞了一些大尺寸图片的压缩策略, 保证 Kindle 的小内存不会爆, 不过只能说尽量可用, 毕竟原理上我审核不到, 这块图片压缩算法不是很懂.

图片是按需下载的, 翻到哪页下哪页, 后面几张提前预取. 追更的时候不用等整章下完才能看第一页. 想离线看的章节, 在详情页批量勾选下载, 之后从"已下载"进去就是本地阅读, 断网也不影响.

特别对版式做了下兼容设计. 漫画毕竟分为竖版, 韩式条漫, 还有 CG 类的横版几种常见类型, Kindle 这种设备毕竟不方便缩放和翻转, 所以加上了自动检测机制. 逻辑倒是简单, 直接从中间页分析漫画页面的比例, 看属于竖版, 横版, 还是条漫. 单行本竖屏翻页, 条漫上下滚动, 横屏则自动翻转屏幕. 默认自动判断, 判不准的话在详情页按单本手动循环切换.

6. 源与插件

不想每加一个源就重发一版插件, 所以源搞成独立的包, 走独立仓库分发, 插件里支持更新漫画源能力, 从漫画源仓库直接拉取最新版本.

目前漫画源能自动检测并更新. 我看 readest 这个项目也做了插件本身的更新能力, 后续可以学习下, 把插件本体的自动更新也加上.

7. 安装

在 GitHub Releases 下载 picayomi.koplugin-x.x.x.zip, 解压后把 picayomi.koplugin 文件夹丢进设备的 koreader/plugins/ 目录, 重启 KOReader 就能在工具菜单里看到. 注意自动生成的 Source code 压缩包是源码归档, 不是安装包, 别下错了.

项目地址 https://github.com/UFOAlastor/koreader_PicaYomi

8. 未来规划

从空目录到能用, 一周左右. 真是 AI 神力, 一年前还在流口水, 现在立马就能落地, 确实方便.

后续可能可以拓展下项目范围, 把轻小说也搞进来, 这样也省去小说同步给 Kindle 的步骤, 直接在线看还是方便许多.

9. 致谢

感谢项目参考:

  • https://github.com/wgh136/PicaComic (原作)
  • https://github.com/hanatsumi/rakuyomi (原作)
  • 另有以上项目的 fork 版本同样参考过: Pacalini/PicaComic, tachibana-shin/rakuyomi

另外, 推荐一个看书的多平台同步软件, 页面设计不错, 而且目前对 Kindle 的支持很好, 能够将手机上的阅读书籍本体以及进度, 批注, 划线都同步到 Kindle 上 -- Readest.
